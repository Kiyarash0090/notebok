## 💡 درباره نیورا (NIVRA)

**نیورا (NIVRA)** یک نرم‌افزار جامع و مدرن برای یادداشت‌برداری، مدیریت جزوه‌های دانشگاهی و درسی، فرمول‌نویسی، ثبت نکات پروژه‌ها و آرشیو فایل‌ها است. این برنامه با هدف فراهم کردن بستری روان، سریع و بدون نیاز به اینترنت (قابلیت کارکرد آفلاین و سرور محلی) طراحی شده و در عین حال امکان پشتیبان‌گیری خودکار در ابر رایگان تلگرام را ارائه می‌دهد.

طراحی بصری برنامه بر پایه اصول **Natural Tones** و **Material 3** انجام شده تا حین مطالعات طولانی‌مدت مانع خستگی چشم شود.

## ✨ ویژگی‌ها و امکانات کلیدی

### ۱. ویرایشگر بلوکی پیشرفته (Block Editor)
- **ساختار بلوکی مدرن**: افزودن، جابه‌جایی و ویرایش آسان انواعی از بلوک‌ها به سبک Notion و Microsoft Word.
- **انواع بلوک‌های پشتیبانی‌شده**:
  - **متن ساده (Paragraph)**: همراه با قابلیت‌های فرمت‌بندی غنی (بولد، ایتالیک، هایلایت، رنگ متن، لینک و...).
  - **عناوین (Headings)**: تیترهای H1 تا H3 با استایل‌دهی منظم.
  - **نقل قول (Quote) و کادر تأکید (Callout)**: با رنگ‌ها و آیکون‌های هشداری برای نکات مهم و امتحانی.
  - **بلوک کد (Code Block)**: همراه با هایلایت هوشمند سنتکس (Syntax Highlighting) و کلید کپی سریع.
  - **فرمول ریاضی (Math LaTeX)**: تایپ و نمایش فرمول‌های پیچیده.
  - **جدول تعاملی (Interactive Table)**: ایجاد و ویرایش جداول با قابلیت افزودن سطر و ستون.
  - **چک‌لیست (Checklist)**: مدیریت وظایف و کارهای انجام‌شده.
  - **گالری چندرسانه‌ای (Media Gallery)**: چیدمان شبکه‌ای تصاویر و ویدیوها با کپشن.
  - **اشکال هندسی (Shapes)**: درج اشکال و دیاگرام‌ها.

### ۲. اشکال هندسی و باکس‌های متنی (Word-like Shapes)
- **تنوع اشکال**: مستطیل، مستطیل گوشه‌گرد، دایره، لوزی، شش‌ضلعی، ستاره، قلب، ابر، بج، فلش یک‌طرفه و دوطرفه، خطوط و باکس متنی (Textbox).
- **تنظیمات ظاهری پیشرفته**:
  - تغییر رنگ بدنه، خط دور (Stroke Style & Width) و درجه شفافیت (Opacity).
  - پشتیبانی از **گرادینت‌های رنگی دو‌تایی** با زاویه قابل تنظیم (۰ تا ۳۶۰ درجه).
  - **الگوهای پس‌زمینه (Pattern Textures)**: نقطه-نقطه‌ای (Dots)، شبکه‌ای (Grid)، خطوط مورب (Stripes)، نقشه‌کشی (Blueprint) و موجی (Waves).
  - **افکت‌های سایه ۳ بعدی (3D Lighting & Depth)**: ایجاد جلوه‌های برجسته و درخشان (Glow/3D Shadow).
  - **چیدمان لایه‌ای (Layering & Positioning)**: قرارگیری شکل پشت متن، جلوی متن، شناور یا به‌صورت Inline.
  - **نوشتن متن درون شکل**: با قابلیت تنظیم فونت، رنگ و جهت چینش متن.

### ۳. تایپ و رندر فرمول‌های ریاضی و علمی (LaTeX & KaTeX)
- **رندر سریع و باکیفیت**: استفاده از موتور قدرتمند **KaTeX** برای نمایش فرمول‌های ریاضی، فیزیک و شیمی.
- **کتابخانه اسنیپت‌های آماده (Math Snippets)**: دسترسی سریع به فرمول‌های پرکاربرد مانند کسرها، انتگرال، حد، سیگما، ماتریس‌ها و نمادهای یونانی.
- **پنجره ویرایش اختصاصی (LatexFormulaModal)**: همراه با پیش‌نمایش زنده (Live Preview) حین تایپ.

### ۴. مدیریت رسانه‌ها، صوت و اسناد (Media & Attachments)
- **پشتیبانی از انواع فایل‌ها**: تصاویر، ویدیوها، فایل‌های صوتی و اسناد متنی/PDF.
- **ضبط‌کننده صوت اختصاصی (Voice Recorder Module)**: ضبط مستقیم صدای استاد یا جلسات و ذخیره مستقیم در جزوه.
- **پخش‌کننده ویدیو و صوت درون‌برنامه‌ای (VideoPlayer & Audio Player)**.
- **نمایشگر پیشرفته اسناد و PDF (PdfPlayer & DocumentViewerModal)**: مشاهده و مطالعه فایل‌های PDF بدون نیاز به ابزار خارجی.
- **مدیریت آپلود (UploadProgressBar)**: نشانگر پیشرفت آپلود فایل‌های سنگین.

### ۵. همگام‌سازی و ذخیره‌سازی ابری با تلگرام (Telegram Cloud Sync)
- **استفاده از تلگرام به‌عنوان دیتابیس ابری نامحدود**:
  - امکان اتصال به تلگرام از طریق Bot API یا اکانت شخصی (GramJS/Telegram API).
  - **پشتیبان‌گیری کامل (Sync DB to Telegram)**: ارسال فایل پایگاه‌داده و پیوست‌ها به چت تلگرام.
  - **بازیابی داده‌ها (Restore DB from Telegram)**: دانلود و جایگزینی دیتابیس از تلگرام تنها با یک کلیک.
  - **انتقال فایل‌های محلی (Migrate Local Files)**: آپلود خودکار تمام تصاویر و فایل‌های ذخیره‌شده محلی به ابر تلگرام.

### ۶. سازماندهی و دسته‌بندی هوشمند
- **مدیریت دسته‌بندی‌ها (Category Manager)**: تعریف دسته‌های اختصاصی با آیکون، رنگ و توضیحات مجزا.
- **سطح اهمیت (Importance Level)**: تعیین اهمیت جزوه در سه سطح *عادی (Normal)*، *مهم (High)* و *حیاتی (Critical)*.
- **مدیریت وضعیت**: قابلیت سنجاق کردن (Pin)، برچسب‌گذاری (Tags)، آرشیو کردن و انتقال به سطل زباله (Trash).
- **خلاصه خودکار (Auto Summary)**: تولید چکیده و خلاصه کوتاه برای هر یادداشت.
- **تاریخچه نسخه‌ها (Version History & Snapshots)**: ثبت خودکار نسخه‌های قبلی یادداشت جهت بازگردانی در صورت نیاز.

### ۷. جستجوی پیشرفته و حالت چاپ (Advanced Search & Print)
- **جستجوی پیشرفته (Advanced Search Modal)**: فیلتر بر اساس کلیدواژه، دسته، سطح اهمیت، برچسب‌ها، وجود پیوست و بازه زمانی.
- **حالت چاپ و خروجی PDF (Print View)**: بهینه‌سازی فرمت نمایش جهت چاپ تمیز جزوه‌ها یا خروجی گرفتن به‌صورت فایل PDF.

## 🛠 پشته فناوری (Tech Stack)

### فرانت‌اند (Frontend)
- **فریم‌ورک اصلی**: React 19 + TypeScript
- **ابزار بیلد**: Vite 6
- **استایل‌دهی**: Tailwind CSS v4 + `@tailwindcss/typography`
- **انیمیشن‌ها**: Motion (`motion/react`)
- **آیکون‌ها**: Lucide React
- **رندر فرمول ریاضی**: KaTeX & `@types/katex`
- **نمایش Markdown و کد**: React Markdown + Highlight.js + Rehype Highlight
- **نمایش اسناد PDF**: React PDF (`react-pdf`)
- **فشرده‌سازی فایل‌ها**: JSZip

### بک‌اند (Backend)
- **سرور**: Node.js + Express 4
- **کامپایلر سرور**: TSX (Dev) & ESBuild (Prod Bundle)
- **پایگاه‌داده محلی**: JSON File Database (`data/notes_db.json`)
- **ذخیره‌سازی فایل‌ها**: سیستم فایل محلی (`data/uploads`)
- **کتابخانه اتصال به تلگرام**: Telegram (`telegram` / GramJS)

## 🚀 راهنمای نصب و اجرا

### پیش‌نیازها
- **Node.js**: نسخه 18 یا بالاتر
- **npm**: نسخه 9 یا بالاتر (یا yarn / pnpm / bun)

### ۱. دریافت پروژه و نصب وابستگی‌ها
پروژه را کلون کرده و وابستگی‌های آن را نصب کنید:

```bash
git clone https://github.com/your-username/nivra.git
cd nivra
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل `.env` بر اساس `.env.example` ایجاد کنید:

```bash
cp .env.example .env
```

### ۳. اجرای برنامه در حالت توسعه (Development)
برای اجرای همزمان سرور Express و فرانت‌اند Vite دستور زیر را بزنید:

```bash
npm run dev
```

پس از اجرا، مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **`http://localhost:3000`**

### ۴. ساخت نسسخه پروداکشن (Build & Production)
برای کامپایل فرانت‌اند و باندل کردن سرور برای محیط پروداکشن:

```bash
npm run build
npm start
```

## 🌐 مستندات APIها (API Endpoints)

سرور Express روی پورت `3000` اجرا شده و مسیرهای زیر را ارائه می‌دهد:

| مسیر (Endpoint) | متد | توضیح |
| :--- | :---: | :--- |
| `/api/notes` | `GET` | دریافت لیست یادداشت‌ها (با پشتیبانی از فیلتر، جستجو و دسته‌بندی) |
| `/api/notes` | `POST` | ایجاد یادداشت جدید |
| `/api/notes/:id` | `GET` / `PUT` / `DELETE` | دریافت، بروزرسانی یا حذف یک یادداشت |
| `/api/categories` | `GET` / `POST` / `PUT` / `DELETE` | مدیریت دسته‌بندی‌ها |
| `/api/upload` | `POST` | آپلود فایل، تصویر، ویدیو یا صوت |
| `/api/telegram/config` | `GET` / `POST` | دریافت و ذخیره تنظیمات ربات/اکانت تلگرام |
| `/api/telegram/test` | `POST` | تست اتصال به تلگرام |
| `/api/telegram/sync` | `POST` | همگام‌سازی و ارسال پشتیبان دیتابیس به تلگرام |
| `/api/telegram/restore` | `POST` | بازیابی پایگاه‌داده از ابر تلگرام |
| `/api/backup/export` | `GET` | دریافت فایل پکیج پشتیبان (ZIP) |
| `/api/backup/import` | `POST` | بازگردانی اطلاعات از فایل ZIP پشتیبان |
